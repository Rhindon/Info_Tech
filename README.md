_Guess The Number_  
This script is written to demonstrate knowledge of Bash scripting, including logical organization, possible user input errors, and functions...with a teeny bit of humor inside the script, itself.

As of the writing of this script, my skills with Bash script writing are very basic. ChatGPT was used to help with some of the logic and syntax, but the script is my own work. I specifically asked ChatGPT to test me on my knowledge and ask quiz-like questions to help me learn more about Bash scripting. I did not ask it to write the script for me. I wanted to see how much I could do on my own, and I wanted to learn more about Bash scripting in the process.

Certainly not the most efficient way to write a Guess The Number game, but it works and is fun to play! This script is especially written for job-seeking purposes. It is not intended to be a perfect script, but rather a working demonstration of my present knowledge of Bash scripting.
